# Desktop

niri, a scrolling tiling compositor: windows open side by side in an endless strip and you scroll along it, instead of being squeezed into the screen. The Caelestia shell (its niri port by Cantfirmed, pinned in `pkgs/niri-caelestia-shell`) draws the bar, launcher, dashboard, notifications, lock screen and power menu. Login is greetd with tuigreet. Configuration: `/etc/niri/config.kdl` (copy it to `~/.config/niri/` to change it) and `~/.config/caelestia/shell.json`.

| Keys | |
| --- | --- |
| Super+Space | launcher |
| Super+D | dashboard |
| Super+Return | terminal (kitty) |
| Super+E / Super+B | files (Dolphin) / browser (Firefox) |
| Super+R | Russian words |
| Super+Left/Right, Super+H/L | scroll along the windows |
| Super+Up/Down, Super+K/J | window or workspace above/below |
| Super+Shift+arrows | move windows |
| Super+Tab | overview |
| Super+F / Super+Shift+F | maximise column / full screen |
| Super+Minus / Super+Equal | narrower / wider |
| Super+V | clipboard history |
| Super+N / Super+Shift+N | utilities / notifications |
| Super+Alt+L | lock |
| Super+Escape | power menu |
| Super+Shift+S, Print | screenshot |
| Super+Q | close window |
| Super+Shift+/ | every key binding |

The wallpaper is in `/usr/share/backgrounds/constellation`; Super+W picks another from that folder.
